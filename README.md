# OpenAA 微信小程序

OpenAA 美国华人生活平台的原生微信小程序客户端，目标是与 [OpenAA.com](https://openaa.com) 共享业务数据和主要功能，包括招聘、房屋、二手、本地服务、新闻、华人导航、DMV、搜索、发布、收藏与个人中心。

> **当前阶段：全功能页面预览 + 逐步真实 API 联调。不是独立工具型小程序，也尚未正式上线。**

## 开发运行

1. 使用微信开发者工具导入仓库根目录。
2. 在本地项目配置自己的小程序 AppID；仓库中为示例配置，严禁提交 AppSecret。
3. 本地预览可根据开发者工具设置调试，但正式真机请求需在微信后台配置 HTTPS request 合法域名。
4. 编译并检查首页、分类、发布、我的及新闻/导航/DMV 入口。
5. 尚未接通后端的入口会明确标注开发中；不可当成真实发布功能。

## 当前提醒

- 原生项目文件在 app.json、pages/、utils/。
- 列表仍需核对 OpenAA 主站真实 API 数据结构和服务端公开字段。

- 发布、微信登录、新闻/导航/DMV 真正业务能力尚未完成。
- 模拟 wx 回归测试不等于微信编译或真机通过。
- 用户已决定：备案、主体资质、服务类目及正式审核待开发预览完善后再处理，但正式上架前必须符合平台规则。

请勿提交任何服务端密钥、隐私数据或生产数据库凭证。
