# OpenAA 美国驾考（微信小程序）

使用微信原生小程序开发的美国 DMV 中文驾照考试学习平台。小程序注册名称暂用「美华人life」，应用内品牌「OpenAA 美国驾考」。

## 当前预览版本

- 纽约州（NY）150 道中文学习题，来源于 `openaa-app/data/dmv/openaa-ny-dmv-questions-v1.json` 的审核快照。
- 分类题库、逐题练习、随机 20 题模拟、交通标志专项、错题本（设备本地存储）。
- 不需要登录，未接入支付，不涉及招聘/房屋/二手等旧功能。
- 学习用途，**非美国 DMV 官方服务**。

## 导入步骤

1. 下载本仓库 `main` 分支 ZIP 并解压。
2. 用微信开发者工具导入项目根目录，将 `project.config.json` 内占位 AppID 切换为自己注册的小程序 AppID。
3. 点击「编译」，查看首页、纽约题库、练习和模拟考试。
4. 交通标志图片来自 `img.openaa.com`，正式调试前需要配置图片加载域名。离线题目文字不依赖网络。

## 架构与后续

- 当前为便于马上预览的**静态题库快照**，不是 OpenAA 主站实时 API 同步。
- 后续通过 OpenAA 公开只读接口接入统一 DMV 数据，增加其他州、题库版本、学习进度。
- 当前中国大陆个人主体「教育信息展示」类目是否允许互动题库未知，先预览，正式审核资格另行核实。

AI 接手时先阅读 [AGENTS.md](AGENTS.md)。

离线校验：`node tests/dmv-smoke.cjs`。
