# OpenAA 微信小程序（第一版工程）

这是原生微信小程序项目，不是 H5 网页包装。当前包含首页、四大分类、分页列表、简易详情、温度和距离换算工具。

## 开始运行

1. 安装微信开发者工具，选择「导入项目」，目录选 `openaa-wechat`。
2. 在 `project.config.json` 将 `touristappid` 改成自己的小程序 AppID，或者先用游客模式预览。
3. 在微信小程序后台配置 `https://openaa.com` 为 **request 合法域名**（需满足后台的证书与域名要求）。
4. 用开发者工具编译，在真机预览测试首页和四个数据频道。

## 上线前必须完成

- **API 核对**：当前只按常见字段适配 `/api/jobs`、`/api/housing`、`/api/secondhand`、`/api/services`，没有读到主站源码，不能保证实际数据结构匹配。需要验证响应分页、状态过滤、详情字段及错误码。
- **接口安全**：API 必须严格只返回公开、已审核数据，不暴露 Service Role、管理接口、私密手机号或其他后台凭据。
- **详情直达**：现在详情通过本地缓存传递，不能独立打开/深链分享；正式发布前需开发 `id` 对应的公共详情 API 和分享路径。
- **微信审核**：账号主体、小程序类目、信息发布/招聘类要求、隐私政策、用户内容安全审核、备案等均须按小程序后台当前要求核实。
- **登录发布**：尚未接入微信登录，不能进行发布、收藏或管理自己的帖子。未来应由服务器交换 `wx.login` 的临时 code 并绑定现有 OpenAA 用户，绝不能把 AppSecret 放到小程序客户端。
- **DMV**：此版本没有集成题库，需确认题库接口和版权合规后开发。
- **小程序码、订阅消息、真实手机端 QA**：尚未完成。

项目用于第一轮本地开发和接口联调，**不是可直接发布的生产版本**。
