# OpenAA 微信小程序（五频道只读版）

当前唯一方向（用户于 2026-10-30 确定）：中国大陆个人主体的**只读开发预览**，与 [OpenAA.com](https://openaa.com) 共用公开数据。

允许：新闻、招聘、房屋、二手、本地服务的列表、筛选、详情、微信分享。
不做：微信登录、我的、收藏、小程序发布与编辑、DMV、华人导航、工具和交易。

发布信息：小程序展示“前往网页版发布”按钮，点击后**复制** `https://openaa.com`，用户自行在浏览器登录发布。个人主体不使用 web-view。

## 本地预览
1. 用微信开发者工具导入仓库。
2. 配置自己的小程序 AppID；**不要上传 AppSecret**。
3. 编译首页、分类、五频道详情与新闻分享入口。
4. 生产请求需要微信后台 HTTPS request 合法域名配置；未经微信编译/真机核验不能称为上线。

## 上线资格提醒
只读并不能保证中国大陆个人主体有资格经营资讯、招聘、房产或分类信息服务。正式审核前核对微信当前开放类目、主体资质、小程序备案与外链限制；当前代码尚未完成这些平台验证。
