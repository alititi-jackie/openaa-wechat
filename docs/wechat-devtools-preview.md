# OpenAA 微信小程序：另一台 Windows 电脑预览检查清单

**当前版本：五频道只读版（新闻、招聘、房屋、二手、本地服务）**。此文档只涉及开发预览，不代表已通过正式发布资格审核。

## 第一次导入
1. 在 https://github.com/alititi-jackie/openaa-wechat 下载最新 main 的 ZIP 并解压。**不要使用旧的 v0.1 ZIP**。
2. 安装微信开发者工具 Stable 版本，微信扫码登录。
3. 选择「导入项目」，目录选择含 `app.json` 和 `project.config.json` 的 `openaa-wechat` 项目根目录。
4. 选择你自己的微信小程序 AppID（`wx...`）。仓库 `project.config.json` 中的 `touristappid` 只是示例，不能用于真实小程序上传或分享。
5. 点击「编译」，打开调试器的「Console」和「Network」观察报错。

## 五频道检查
- 首页只显示新闻、招聘、房屋、二手、本地服务五个入口；底部只有「首页」「分类」。
- 首页有四类信息的最新帖子；某个频道断网时应显示独立错误，不影响其他频道。
- 分类页的四个标签可左右滑动，列表卡片能显示标题、地点、价格和可用缩略图。
- 搜索关键词、地区和价格筛选后，结果符合主站对应公开信息；下拉刷新与翻页正常。
- 点击帖子进入详情；通过分享路径冷启动后能够独立加载。下架信息不显示原内容。
- 新闻入口展示列表、分类、文章正文和分享。
- 「前往网页版发布」仅弹窗，选择复制网址后复制 `https://openaa.com`，不会在小程序内打开登录或发布界面。
- 不出现个人中心、微信登录、收藏、DMV、华人导航和工具中心。

## 如果出现 `request:fail url not in domain list`
1. 确认小程序后台「开发管理 → 开发设置 → 服务器域名」中是否允许 `https://openaa.com` 作为 **request 合法域名**（不包括路径）。该配置需要符合微信当前规则。
2. 检查最终 API 域名是否发生 301/302 重定向；如果实际请求的是其它主机，需要核实最终域名以及微信要求。
3. 开发者工具里的「不校验合法域名」只能帮助本地调试，不能代替正式配置，也不能代表真机必定可用。
4. 图片可能使用独立 CDN 或 Supabase Storage 域名，图片相关域名也需要按微信规则单独检查。

## 如何反馈排查信息
请提供三张截图：①微信开发者工具整个窗口；②调试器 Console 报错；③Network 中失败请求的 URL、状态码和响应摘要。**不要上传 AppSecret、个人令牌、生产数据库密钥或用户隐私。**

## 云端自动测试
仓库 GitHub Actions 使用 `node tests/validate.cjs` 检查项目结构和模拟 wx 回归。即使这些测试通过，仍要真实微信编译和真机测试。
