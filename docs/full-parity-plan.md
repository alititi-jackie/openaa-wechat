## 服务边界
- 只调用有明确公开契约的 OpenAA API；后端仍使用唯一 Supabase 数据库。
- 公共列表/详情由服务器保证审核状态、账号状态和公开字段最小化。
- 微信登录：客户端 wx.login → 服务端安全换取身份 → 与 OpenAA 账号绑定须验证所有权；服务端控制会话和发布权限。
- AppSecret、Service Role 等仅服务端保存；不能写在小程序、GitHub 或日志。
- 发布涉及图片上传、审核、账户 restricted/banned 状态；与主站一致。
- 分享详情必须使用 channel/id 深链，支持冷启动独立加载，不依赖本地缓存。
- 不单独开发换算器、二维码生成器等独立工具。已有旧工具页不再注册到 app.json，可后续清理。

## 开发阶段
1. 全页面原生预览：导航、布局、状态与入口；真实功能未完成的地方明确提示。
2. 真实公开数据：四类业务 + 新闻 + 导航 + DMV 的接口契约和只读展示。
3. 详情、搜索、筛选、多图、分享与最近浏览。
4. 微信登录、账号关联、收藏与发布管理（需后端安全审查）。
5. 微信开发者工具编译、真机验证、性能和错误处理。
6. 用户另行处理主体资质、备案和审核，正式发布前核实全部要求。
