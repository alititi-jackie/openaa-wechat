# OpenAA 微信小程序完整产品需求（PRD）

版本：2026-10-30。状态：目标规范，不代表已实现。

## 愿景与原则
将现有 OpenAA 美国华人生活平台的主要业务完整延伸到微信小程序，服务在美国生活的华人。不是独立工具站，也不是仅用 WebView 包裹网页。保留与主站相同的业务语义、状态和权限，界面适应微信原生交互。

## 用户旅程
1. 游客打开首页，看到主要分类、最近公开信息、搜索入口。
2. 浏览招聘/房屋/二手/服务列表，按地区、类别、关键词筛选，进入可独立加载详情。
3. 将某个帖子分享给微信好友，接收方冷启动直接到相应内容；下架内容展示失效提示。
4. 浏览新闻、导航、DMV 题库与练习。
5. 登录后完成账号关联，收藏、查看浏览历史、发布/编辑/管理帖子，权限和审核与主站一致。
6. 对不实信息可反馈/举报；联系方式默认隐藏，按需展开。

## 关键交互
- 底部导航：主页、分类、发布、我的；新闻/导航/DMV 由首页入口或频道跳转。
- 分类标签手机横向滑动，必要时吸顶；卡片间距、返回与分享风格统一。
- 列表提供骨架加载、空态、错误重试、下拉刷新、分页防重复及竞态隔离。
- 联系方式默认隐藏；展开展示由服务端公开字段规则决定。
- 图片支持预览；禁止未授权的外部跳转和不可靠的分享路径。
- 新闻与 DMV 内容不可虚构，必须来自已核实数据或明确标注测试演示。
- 每个业务功能应有未登录、登录、受限、下架、无数据、弱网/超时状态。

## 非目标
- 不另做温度/里程转换、二维码生成、独立工具中心。
- 不做脱离主站的数据后台或第二套内容审核系统。
- 当前不以微信账号备案和正式上线审核为开发阶段阻塞条件；但正式发布时必须合规。

## 验收
- UI：所有目标导航可打开，无误导性假成功；主要手机尺寸无布局溢出。
- 数据：主站与小程序看见同一批合法公开内容，字段与状态一致。
- 分享：帖子链接支持冷启动，删除/下架不可泄露内容。
- 权限：受限账号不可越权发布/编辑，敏感字段不在公开 API 泄露。
- 稳定性：编译和真机关键流程通过，错误可恢复。
