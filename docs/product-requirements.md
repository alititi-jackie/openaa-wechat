# OpenAA 微信小程序五频道只读产品需求（2026-10-30）

## 产品定位
中国大陆个人主体的小程序预览版。与 OpenAA.com 共享合法公开数据，但不提供用户账户与信息写入功能。**暂不表示一定符合个人主体上线资质。**

## 唯一在范围内的功能
| 频道 | 小程序能力 | 数据来源 |
|---|---|---|
| 新闻资讯 | 分类、文章列表、正文、分享 | 主站公开新闻 API |
| 招聘求职 | 公开信息列表、关键词/地区/薪资筛选、详情、分享 | 主站 posts API type=job |
| 房屋租售 | 公开房源列表、关键词/地区/租金筛选、详情、图片、分享 | type=housing |
| 二手交易 | 公开列表、关键词/地区/价格筛选、详情、图片、分享 | type=marketplace |
| 本地服务 | 公开列表、关键词/地区筛选、详情、分享 | type=service |

## 导航与发布引导
- 底部 Tab **只有首页、分类**。
- 首页快捷入口 **只有五个频道**，不显示 DMV、导航、工具。
- 首页与分类页提供“前往网页版发布”按钮，弹窗说明，然后让用户**复制** `https://openaa.com`，去手机浏览器自行登录和发布；不使用 web-view，不保证能够直接打开浏览器。
- 没有微信登录、注册、账号绑定、收藏、最近浏览个人中心、站内发布/编辑、支付与交易。
- 详情不暴露隐私联系方式或原始数据库记录，公开规则由主站控制。

## 质量要求
- 中文、手机优先；横向分类、加载/失败/空态、搜索筛选、下拉刷新、分页、防竞态。
- 新闻及帖子分享必须可在冷启动时用 slug/id 重新向主站获取内容。
- 微信开发者工具编译、iOS/Android 真机、合法域名、主站真实接口及内容安全均须单独验证。
- 个人主体开放类目、招聘/房产/新闻资质、备案、外部网页引导要在正式申请审核前核实。**只读不是通过审核的保证。**

## 非目标
不做 DMV、华人导航、换算器、二维码、工具中心、微信登录、收藏、发布、编辑、我的页面、广告管理、用户私有内容或第二套数据库。网站 OpenAA.com 现有功能不受小程序缩减影响。
